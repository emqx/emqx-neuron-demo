# Main-page layout drafts

Open `/static/drafts/index.html` on the local operator service (normally
<http://localhost:8080/static/drafts/index.html>). The top bar switches
between three layouts:

- **A — Device controls:** selected for the live main page. The A link opens
  `/`, with compact device headers, inline settings and larger Neuron panels.
- **B — Shared tray:** select an illustrated device to edit its settings below
  the factory map.
- **C — Command composer:** edit the selected device below the command feed;
  the EMQX strip spans the page.

The remaining B and C previews use local sample data. Claims, commands, telemetry and batches
are simulated in the browser. They do not connect to the broker or control
the running demo. Product-screen links open the existing local services.

Both appliance drawings are copied from the original showcase template.
Logos and fonts reuse the project's existing brand assets.
