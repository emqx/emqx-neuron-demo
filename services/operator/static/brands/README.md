# EMQ brand assets

`emq.svg`, `emqx.svg`, and `neuron.svg` are unmodified copies of
`assets/icons/brands/` in the EMQX website repository (`~/work/emqx.com`).
They are the company wordmark, EMQX product mark, and EMQX Neuron product mark
used by that site's header and brand resources page.

The demo follows `DESIGN.md` and `assets/css/tailwind.css` from that
repository: primary purple `#5e4eff`, Neuron blue `#189bfe`, and neutral
surfaces and typography. Green is reserved for actual live/success status.

The local Roboto WOFF2 files in `../fonts/` are copied from the website's
`public/fonts/roboto/` directory (regular, 500, 700). Keeping fonts and logos
local allows the demo to run without external asset requests.
